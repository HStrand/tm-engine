## API / protocol notes

- 2026-04-18 Human vs AI mode: CLI mode 3 creates a game where human is P0, AI is P1. Use `scripts/turn-ai.sh <gameId>` to see state/hand/legal moves as P1, and `scripts/submit-ai.sh <gameId> '<json>'` to submit moves as P1. The CLI polls and shows each AI move to the human. Join an existing game by its ID — no need to create one yourself.
