# Corporations

Format: 2-player, base game + Prelude, Corporate Era, Draft variant.

Refer to `tm-strategy` for the terraformer vs. engine archetype axis —
each corporation naturally leans toward one end.

Individual corp strategy files are in `corps/`. **At setup**, read both
offered corps to decide. **After choosing**, re-read your corp file at
the start of each generation (alongside `tm-strategy`) to stay aligned
with corp-specific synergies.
